# Демо-сайты для Братска

Три одностраничных демо для показа клиентам: цветочный салон, кофейня и гостевой дом. Все страницы адаптированы под телефон, работают без сборки и открываются по ссылке.

## Ссылки

- Общая страница: https://urasokolik.github.io/bratsk-demos/
- Цветы «Пион»: https://urasokolik.github.io/bratsk-demos/flowers/
- Кофейня «Тёплый хлеб»: https://urasokolik.github.io/bratsk-demos/cafe/
- Гостевой дом «Таёжный берег»: https://urasokolik.github.io/bratsk-demos/hotel/
- Генератор персональных ссылок: https://urasokolik.github.io/bratsk-demos/builder.html

## Персональная ссылка

В генераторе выберите шаблон, введите название и телефон клиента. Он выдаст ссылку вида:

```
https://urasokolik.github.io/bratsk-demos/cafe/?name=Название&phone=+7...
```

На сайте подставятся название в шапке и подвале, телефон во всех кнопках, ссылки `tel:` и WhatsApp. Название и телефон можно также добавить вручную в адресную строку.

## Что внутри

- `index.html` — страница со всеми демо.
- `flowers/`, `cafe/`, `hotel/` — три сайта.
- `builder.html` — генератор ссылок и сообщения для WhatsApp.
- `credits.html` — источники и лицензии фотографий.
- `assets/` — шрифты и изображения.

Каждый сайт — отдельный HTML-файл со своими стилями. Данные клиента подставляются через параметры `?name=` и `?phone=`.

## Локальный запуск

```bash
cd bratsk-demos
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для проверки с телефона используйте IP компьютера в той же Wi-Fi сети.

## Правки

- Телефон по умолчанию: `+7 (3953) 00-00-00` (заглушка). Замените в HTML или используйте генератор.
- Плашка «Демо-версия» находится в начале каждой страницы (`.demo-strip`). Для реального сайта её нужно убрать.
- Тексты, цены, адреса и меню — примеры. Перед публикацией клиенту замените на его данные.
- Фотографии — Wikimedia Commons. Авторы и лицензии указаны в `credits.html`. Для коммерческого сайта лучше использовать фото клиента.

## Публикация

Репозиторий: `urasokolik/bratsk-demos`, ветка `main`, GitHub Pages из корня. Чтобы обновить сайт:

```bash
git add .
git commit -m "Update demos"
git push
```

Pages пересоберётся автоматически за 1–2 минуты.

## Важно

Демо не содержат базу лидов и контакты организаций. Это только примеры оформления. Перед отправкой клиенту проверьте, что название и телефон подставлены правильно.
